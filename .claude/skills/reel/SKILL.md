# Reel / Short Generator

Produce a **complete post package** for one short-form vertical video. If Joey asks
for a batch (e.g. "make today's posts"), produce one package per post, each with a
different hook angle so the feeds don't look repetitive.

## Every package must contain

1. **Title** — a short internal name for the post (e.g. "ADHD brain dump hook").
2. **Hook (first 1–2 seconds)** — spoken line + matching on-screen text. This is the
   most important part; make it stop the scroll.
3. **Script** — 15–35 seconds total, written as a shot list:
   - what's on screen (planner pages, screen recording of the PDF, hands writing, etc.)
   - the voiceover or text-overlay for each shot
   - keep shots 1–3 seconds each; fast pacing
4. **CTA** — always end by sending viewers to the store. Default:
   "Link in bio — Infinite 4 You on Etsy. Instant download."
5. **Captions — one per platform** (they should NOT be identical):
   - **TikTok**: casual, 1–2 lines + 3–5 hashtags in caption
   - **Instagram Reels**: slightly longer, line breaks, 5–10 hashtags at the end
   - **Facebook Reels**: conversational, minimal hashtags (0–3)
   - **YouTube Shorts**: title (max ~70 chars, keyword-first) + description with
     store link placeholder and #Shorts
6. **Hashtags** — mix of: niche (#digitalplanner, #plannerpdf, #printableplanner),
   audience (#adhdplanner, #momlife, #studytok — whichever fits the angle), and
   broad (#planwithme, #productivity). Never the same exact set twice in a row.
7. **Sound suggestion** — describe the type of trending audio to pick
   (e.g. "calm aesthetic lo-fi" or "fast trending sound with beat drops") since
   actual trending sounds must be picked inside each app.

## Content angles to rotate through

Vary these so the account never posts the same style twice in a row:
- **Problem → solution**: a relatable pain ("my brain won't shut off at night") → the planner fixes it
- **Flip-through / aesthetic**: satisfying page flips or scrolling through the PDF
- **Plan with me**: filling in a page in real time
- **Before/after**: chaotic notes vs. organized planner
- **Tips content**: "3 things to put in your planner every Sunday" (value first, soft sell)
- **New product / restock announcement**
- **Social proof**: reviews, download counts, "you guys keep buying this one"

## Rules

- Vertical 9:16, designed to work with sound OFF (on-screen text carries the message).
- Never promise results ("this will change your life" is fine as hype; no income/medical claims).
- Etsy is always called "the store" or "Infinite 4 You on Etsy" — link goes in bio/description.
- If Joey provides real product names or listing links, use them verbatim; otherwise
  refer to "our planner PDFs" generically and note where to substitute the real name.
- Output everything in plain text Joey can copy-paste from his phone.
