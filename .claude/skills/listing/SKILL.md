# Etsy Listing Writer

Produce complete, copy-paste-ready Etsy listing copy for a digital product.

## Every listing must contain

1. **Title** — up to 140 characters. Front-load the highest-value keywords; readable,
   not keyword soup. Pattern:
   `[Main keyword] | [Audience/use keyword] | [Format keyword] | Instant Download`
   Example: `ADHD Daily Planner PDF | Printable Brain Dump & To Do List | US Letter & A4 | Instant Download`
2. **13 tags** — Etsy allows exactly 13, each max 20 characters. Rules:
   - all 13 used, always
   - multi-word phrases beat single words ("adhd daily planner" > "planner")
   - mix: exact product, audience, use-case, format, occasion/gift angle
   - no tag repeats a word combination already fully contained in another tag
3. **Description** with this structure:
   - Hook line (the problem it solves, one sentence)
   - ★ WHAT YOU GET — bulleted file/page contents
   - ★ HOW IT WORKS — instant download, print at home or use on tablet, 2–3 steps
   - ★ DETAILS — page count, sizes (US Letter/A4), file format
   - ★ PLEASE NOTE — digital product, no physical item shipped, no refunds on
     digital downloads (per Etsy norms), colors may vary when printed
   - Closing line inviting them to check the rest of the store
4. **Image plan** — Etsy allows 10 photos + 1 video. List what each slot should show:
   cover mockup, inside pages, size/format infographic, "what you get" flat lay,
   lifestyle mockup, how-to-download graphic, etc. Remind Joey a listing video
   can be a reused reel (see the `reel` skill).
5. **Price + attributes suggestion** — price, category, and the "digital download"
   listing type.

## Rules

- Never claim physical shipping; these are digital downloads.
- Keywords must reflect real search behavior (planner pdf, printable planner,
  digital planner, goodnotes planner, adhd planner, budget planner, etc.).
- If Joey pastes an existing listing, audit it against every rule above and rewrite it.
- American spelling (Etsy's main audience is US).
